# D4 · Операционализация до расчётов

Принимается приложенный бриф. Панель строго из девяти старых A-only снимков
`separate/raw SS`, по шесть независимых одношаговых свидетельств B из
каждого снимка. Входы, sealed прогнозы и два исходных кандидата D1/D2
сверяются побитово. Предварительный прогон полностью проверяет один блок
перед запуском всей панели. Состояние проверяется после замены K и возврата.

Норма задана отдельно для каждого случая как норма B3-кандидата уже после
покоординатного clipping. В каждой строке матрицы фактическая норма —
`norm(K_after − K_before)`, а допустимое относительное отклонение `1e-12`.
Для каждого ненулевого направления предельная норма на том же луче равна
`clip * norm(u) / max(abs(u))`. Точки за пределом отмечаются
`INFEASIBLE_MATCH` без проекции на другое направление. Вблизи ровной границы
допускается округление множителя вниз в пределах допуска нормы. Предложенные
компоненты обязаны лежать строго в `[-clip,+clip]`, нулевые координаты
сохраняются. Для вычитания хранимых float допускаются четыре ulp от масштаба
K, с явным сохранением фактического максимума. Нули и nonfinite отдельно.

Запрошенные контрасты по обеим исходным нормам публикуются включая число
допустимых пар. При отсутствии пары дополнительное сравнение направления
на всей панели использует одинаковый для данной записи радиус
`min(r_raw,r_ctx)`. Это одна из уже запланированных пар, без нового плеча.
Её анализ заранее зарегистрирован и не отбирает случаи по эффекту. Одно
из двух номинальных положений масштаба может быть больше другого в любой
из сторон, поэтому знак обозначается как raw-радиус минус ctx-радиус.

Непосредственные показатели — NLL и margin на том же токене A и B. Другие
пять токенов каждого контекста считаются отдельно и с равным весом внутри
свидетельства. Влияние на accuracy измеряется на argmax, отдельно сохраняются
потерянные и приобретённые ответы. Сравнения признака и масштаба считаются
на парных событиях с одинаковыми чтениями, потом усредняются по блокам.
95% ДИ строится прежним перекрёстным bootstrap по seed и mapping. Интервал
по неполной группе блоков не присваивается. Отрицательные контроли K0 и
чужая K из A-only следующего mapping того же seed находятся вне факториала.

Поддержка направления на A означает верхнюю границу ДИ ниже нуля для
`CTX − RAW` в NLL того же токена при равных фактических нормах. Основное
обобщение по development-панели использует парный сравнимый меньший радиус.
Результат на большем радиусе относится к физически допустимым строкам.
`SCALE_ONLY` требует, чтобы весь ДИ эффекта направления лежал внутри
±0,01 NLL, примерно трети прежнего локального эффекта A. Несигнификантность
сама по себе даёт `UNDECIDED`. Пользу для B показываем и относительно NONE,
и относительно RAW на той же норме, отдельно NLL и новые правильные классы.
Если B проигрывает raw по NLL с положительной нижней границей ДИ,
это поддерживает `TRADEOFF`. C1 остаётся закрытым независимо от D4.

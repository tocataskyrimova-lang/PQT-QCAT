## 2. Математическая модель частичного перекрытия B-кодов

Пусть для каждого токена $x \in \{1, \dots, 6\}$ задан вектор входа $b_x \in \mathbb{R}^{48}$.  
В базовом неперекрывающемся режиме ($\rho = 0$):
$$b_i = 8.0 \cdot e_i, \quad i \in \{1, \dots, 6\},$$
где $e_i$ — $i$-й стандартный базисный орт.

Для введения контролируемого перекрытия между старыми ($i \in \{1, 2, 3\}$) и новыми ($i+3 \in \{4, 5, 6\}$) входами при параметре корреляции $\rho \in [0, 1)$ задаются векторы:
$$b_i = 8.0 \cdot e_i, \quad i \in \{1, 2, 3\},$$
$$b_{i+3} = 8.0 \cdot \left(\sqrt{1 - \rho^2} \, e_{i+3} + \rho \, e_i\right), \quad i \in \{1, 2, 3\}.$$

Свойства конструкции:
1. **Изометрия нормы:** $\|b_x\|_2 = 8.0$ строго для всех $x \in \{1, \dots, 6\}$.
2. **Контролируемое перекрытие:** скалярное произведение $\frac{\langle b_i, b_{i+3} \rangle}{\|b_i\| \|b_{i+3}\|} = \rho$.
3. **Ортогональность непарных входов:** $\langle b_j, b_k \rangle = 0$ для всех $j \ne k$ и $k \ne j+3$.
4. **Различимость:** матрица Грама $G = B^T B$ строго невырождена при всех $\rho < 1.0$.

## 5. Измеряемые метрики

На контрольных точках (`pre_new`, `post_new_pre_tail`, `post_tail`):
1. **Accuracy (Q):** Доля верных классификаций в $\{1, 2, 3, 4\}$.
2. **Signed Target Margin:**
   $$M = z_{\text{target}} - \max_{c \ne \text{target}} z_c.$$

   $$\text{NLL} = -\log \left( \frac{\exp(z_{\text{target}})}{\sum_c \exp(z_c)} \right).$$
4. **Режимы считывания:**
   - `structural_reset`: сброс скрытого состояния $Z \to \psi_0$ перед подачей запроса.
   - `carry_state`: удержание текущего состояния $Z$ после задержки 1000 тактов покоя.

## 1. Точная математическая формулировка считывания

Для каждого дискретного запроса (токена) $q \in \{1, \dots, 6\}$ с входным вектором $b_q = B[:, q]$ выходная логит-репрезентация $F_q(K)$ определяется полной нелинейной динамикой 6-эшелонного ядра за $T = 8$ физических тактов интегрирования методом Хойна (Heun step):

$$F_q(K) = W_{\text{readout}} \, Z_T(K; Z_0, b_q),$$
где:
- $Z_0 = \psi_0 \in \mathbb{R}^{48}$ — начальное квазистационарное состояние ядра;
- На каждом такте $t \in [0, T-1]$ вычисляется вектор токов:
  $$I_t = K Z_t + b_q,$$
  с покомпонентной нелинейностью (гейтинг, tanh, проекция вихревого оператора $A$ при `enable_vortex=True`):
  $$\tilde{Z}_{t+1} = \text{Heun}(Z_t, I_t, A, \dots);$$
- $W_{\text{readout}} \in \mathbb{R}^{4 \times 48}$ — проекционная матрица считывания классов $c \in \{1, 2, 3, 4\}$.

Параметрический вектор памяти определяется как векторизация матрицы $K$:
$$\theta = \text{vec}(K) \in \mathbb{R}^{2304} \quad (48 \times 48 = 2304).$$
В случае маски обновлений (например, разрешены только обновляемые синапсы) подпространство имеет размерность $p \le 2304$.

## 2. Якобианы чувствительности и стек запросов

1. **Якобиан скрытого состояния ядра:**
   $$S_q = \frac{\partial Z_T(K; Z_0, b_q)}{\partial \theta} \in \mathbb{R}^{48 \times 2304}.$$
2. **Якобиан выходных логитов по токену $q$:**
   $$J_q = \frac{\partial F_q(K)}{\partial \theta} = W_{\text{readout}} \, S_q \in \mathbb{R}^{4 \times 2304}.$$
3. **Объединённый системный стек логитов по всем 6 запросам панели:**
   $$J_{\text{stack}} = \begin{bmatrix} J_1 \\ J_2 \\ \vdots \\ J_6 \end{bmatrix} \in \mathbb{R}^{24 \times 2304}.$$

## 3. Верификация Якобиана центральными разностями

Для произвольного единичного направления возмущения памяти $v \in \mathbb{R}^{2304}$ ($\|v\|_2 = 1$) и шагов сетки возмущения $\epsilon \in \{10^{-2}, 10^{-3}, 10^{-4}, 10^{-5}\}$ вычисляется центрально-разностная производная:
$$\Delta_\epsilon(v) = \frac{F_q(\text{mat}(\theta + \epsilon v)) - F_q(\text{mat}(\theta - \epsilon v))}{2\epsilon}.$$
Критерий согласованности:
$$\frac{\|\Delta_\epsilon(v) - J_q v\|_2}{\|J_q v\|_2 + 10^{-8}} < \delta_{\text{tol}} \quad \text{при оптимальном } \epsilon.$$

## 4. Спектральный анализ SVD и размерность нуль-пространства

Сингулярное разложение системного якобиана:
$$J_{\text{stack}} = U \Sigma V^T, \quad \Sigma = \text{diag}(\sigma_1, \sigma_2, \dots, \sigma_{24}).$$
Анализируемые инварианты:
1. Спектр сингулярных чисел $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_{24} \ge 0$.
2. Число обусловленности: $\kappa = \sigma_1 / \sigma_{24}$ (или относительно численного машинного нуля $\epsilon_{\text{mach}} \cdot \sigma_1$).
3. Эффективный ранг $r_{\text{eff}} = \operatorname{rank}(J_{\text{stack}})$.
4. Теоретическая размерность ядра (null-space): $\dim(\ker(J_{\text{stack}})) = 2304 - r_{\text{eff}} \ge 2280$.

## 5. Геометрия Guard на Accuracy: Полиэдральный конус против Линейного Ядра

Важнейшее математическое различие:
Сохранение дискретного ответа $\arg\max_c F_{q, c}(K) = y_q$ задаётся не линейным равенством $J_q \delta\theta = 0$, а системой строгих линейных неравенств (полиэдральный конус допустимых возмущений):
$$\forall c \ne y_q: \quad (F_q(K) + J_q \delta\theta)_{y_q} - (F_q(K) + J_q \delta\theta)_c > 0 \iff (J_{q, y_q} - J_{q, c}) \delta\theta > -(F_{q, y_q}(K) - F_{q, c}(K)).$$
Следовательно:
- Возмущения $\delta\theta$ из нуль-пространства $\ker(J_{\text{stack}})$ дают тождественно нулевое изменение логитов ($\Delta F_q = 0$), гарантируя точное сохранение логитов и точности.
- Возмущения $\delta\theta \notin \ker(J_{\text{stack}})$ МОГУТ изменять логиты, но сохранять правильный класс, если они лежат внутри полиэдрального конуса положительного маржина.

## 6. Внешний декодер памяти (External Reader Test)

Для строгой проверки гипотезы о наличии полезной функциональной информации в $K$, которая потенциально «заблокирована» считывателем $W_{\text{readout}}$:
1. Обучается регуляризованный внешний декодер (Ridge / Logistic Regression) непосредственно на признаках $\text{vec}(K)$.
2. Применяется строгое разделение между историями/картами (Cross-Validation across histories).
3. Контроль: тест с перемешиванием меток (Label-Shuffle Baseline).
4. Если точность внешнего декодера на независимом тесте значимо превышает случайный уровень (25%) и превосходит baseline с перемешанными метками, в матрице $K$ содержится декодируемая информация о целевых соответствиях.

# LIFE-001 — протокол до первого эксперимента

Цель: работающая непрерывная система с persistent состоянием, генерацией
символов, online-пластичностью по отложенной обратной связи и измеримой
консолидацией. Не цель: рекорд классификации, имитация сознания или доказательство
необходимости PQT. Исходный v0.1 не меняется.

Система получает явный идентификатор контекста и символ из алфавита восьми
символов. Среда использует разные неизвестные системе перестановки алфавита.
Сначала выдаётся предсказание, затем через несколько событий приходит правильный
ответ. Правильный ответ недоступен encoder/core/predict до выдачи результата.
Генерация — авторегрессивное применение выученного перехода к собственному
предыдущему символу. Это конечный символический язык, не естественная речь.

Одна жизнь: последовательно вводятся четыре правила в четырёх явных контекстах,
потом длинная пауза без внешнего входа, возврат к старым контекстам и новая
версия правила в новом контексте. Состояние не сбрасывается. При смене правила
без нового контекста отдельно проверяется конфликт и забывание. Невозможно
восстановить два противоречивых правила без наблюдаемого признака их различия.

План: development seeds11/12 для отладки и ограниченного выбора скорости
online learning; итоговые seeds101–105 не используются для подбора.
Сравнения: полный PQT; A=0; простой leaky core; отключённое обучение;
нет replay; нет консолидации; сброс core между событиями; общее readout
вместо context gates. Все варианты получают один поток событий и feedback.

Планируемые измерения: prequential accuracy до feedback, время адаптации
в числе наблюдений, sequence exact match свободной генерации, сохранность
старых правил, delta настоящих synaptic weights, изменение физических W,
активность во время idle, finite state, размер памяти, способность учить
новые правила после нескольких смен. Паузы сравниваются с парным snapshot
без фоновой деятельности и с отключением replay/консолидации.

Критерий функционального демонстратора: ноль invalid states, ровно одно
логическое initial_state на жизнь, причинный порядок predict→feedback,
точное продолжение из snapshot; online late accuracy >90% хотя бы на
development sanity. Итоговые невыполненные критерии публикуются. Для
утверждения безопасного idle заранее используется допуск ухудшения ≤5 п.п.
на среднем по seeds; это пилотный критерий, не гарантия для всех будущих входов.

PQT A/энергия — гипотеза вычислительного ядра. Context gates, replay,
eligibility и перенос fast→slow — отдельно добавленные инженерные механизмы.
Нельзя приписывать их эффект математике PQT без успешных абляций.

Непрерывность означает один event/tick loop без отдельных train/eval фаз
и без остановки для optimizer.fit. Все обновления сериализованы внутри
tick для детерминизма; это логически совмещённая работа, не обещание
физически параллельного исполнения на нескольких процессорах.
